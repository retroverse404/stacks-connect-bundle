Interaction model

How it flows

The flow mirrors a guided dry run: orient the person, prove the wallet is ready, justify the mint, then show the asset without jumping panes. Each block gates the next so the screen always tells the user what happens now.

  1. Entry calms the room, confirms Leather pairing, and states the promise in plain words.
  2. Dashboard shows wallet readiness, recent Stacks signal, and mint eligibility so the operator knows whether to proceed.
  3. AI Guide explains why this mint exists and keeps the mint button locked until the story lands.
  4. Mint calls the SIP-009 contract through Leather, shows fees + tx hash inline, and keeps the person on the same surface until confirmation.
  5. Explore swaps inline media so the new collectible occupies the same canvas immediately.
